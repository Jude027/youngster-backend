How Role Price Mapping works
Every user has a Role (e.g. Dealers, Agents, Customers). When they open their Referral Prices page the "Original Price" column will display the price taken from whichever Base Price column you map to that role here.
Example: map Dealers → Dealers column and Agents → Agents column so each group sees the price that was set for them in Base Prices.
If no mapping exists for a role the system automatically falls back to Master Price values.
